大盘助手 0.34.0 / versionCode 38 — 课表导入

实现：日历页“导入”，全局 AI 日历 import_courses 入口。
每名用户在自己的设备登录官方教务站，读取本人的学期起始日期、节次时间及全部课程明细。
本机 DOM 读取与解析，无账号/密码/学号固定配置；不转发课表到 AI，不复制桌面登录态到手机。
支持范围为当前本科教务系统的已验证页面形态，不代表所有专业、所有排课形式都已实测。

实际网页验证（2026-10-15）：
学校 HTTP 教务入口正常跳转到 HTTPS 统一认证；直接 HTTPS 教务入口连接失败。
用户自行登录后查看我的课表、全部课程和打印版。
可读取学期起点、12 节课起止时间、课程编号/名称、周次、星期、节次、教室及教师文本。
样本 10 门课程，其中 7 门有排课、3 门不排课。明细存在分段单双周、教师分段以及第 7 周和后续周教室不同。
未替用户写入课表；未保存账号密码、认证 cookie、学号到项目或安装包。

导入行为：
默认只导入今天起的课次，可切换整个学期、勾选课程、查看原始排课和示例日期时间。
默认课程路程 20 分钟，出发提醒可关闭。
不排课课程只展示说明，不编造时间。解析不支持的格式或互相冲突的同一课次时，整批停止，不部分导入。
稳定课次 ID 防止相同输入重复导入。已有记录有差异时保留，避免覆盖用户编辑；不支持自动删除旧调课记录。
写入前保存本机恢复副本，批量原子保存后再安排提醒。

核查：
assembleDebug 成功；66 项 JVM 检查通过，0 失败，含 7 项课表专用检查。
用匿名课程和地点复现所观察周次形态，展开 199 课次；没有把个人课表写入 App。
58 项页面工具目录检查通过，另新增全局 import_courses 操作。

真机：
PYC110 / <DEVICE_SERIAL> 覆盖安装返回 Success。
未自动打开或操作手机应用；手机 WebView 登录、读取和用户确认写入仍待实际体验。
无服务器变更；无付费 AI 调用。
