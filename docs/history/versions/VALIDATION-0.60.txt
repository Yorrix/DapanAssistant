0.60.0 / versionCode 75 (2026-10-23)

Map changes:
- A01 labels are one N/S/W/E group at all zooms; minimum spacing and screen-edge
  clamping prevent individual labels from disappearing. Shifted labels keep leader
  lines and can be tapped. Draw above route endpoint circles.
- Map turns always use frame-based smoothing. Removed preference, toggle and AI
  smoothTurn argument; orientation still offers fixed/follow.
- Endpoints now project onto road segments, including splitting the same segment
  twice when needed. Compare connected networks by full path plus approach distance.
- Dijkstra shortest path first; replacement paths use existing edges only and are
  loop-free. Filter near-parallel source-map duplicates; provide at most one distinct
  alternative. Local corridor exclusion searches are used when duplicates obscure
  an alternative. No roads are invented. No switch if no distinct candidate found.
- Compact route switch shows shortest/alternative and full approximate distance;
  AI route_select can switch too. Selected index survives moving-start recalculation.
