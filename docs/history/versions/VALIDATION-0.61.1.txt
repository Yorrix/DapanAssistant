大盘助手 0.61.1 自测与修复记录
日期：2026-10-24

本次采用三路子代理并行核查：工具参数与数据写入、对话状态与权限、Android 存储与重启恢复；主代理负责真实模型对话、自测失败修复和最终整合。后台隔离回归随后并行完成。

最终验收
• 本地逻辑与随机回归：1080 项执行通过，0 失败。共 74 个测试类，另有 1 项付费模型测试在离线运行时按设计跳过，已由下面的在线验收单独执行。
• 真实 DeepSeek Flash 对话：覆盖 159 个场景、162 轮对话。最后完整一轮 160/162 通过；1 项晨签时间设置多余追问已修复，另 1 项为上游网络失败。随后相关 28 轮专项复测全部通过，当前覆盖集无未解决失败。未把多轮重跑计为更多独立场景。
• 自然语言覆盖口语、停顿、自我纠正、否定、缺信息、多轮追问、跨页面、批量操作和组合要求；最终结果按上述完整轮次及修复后复测共同计算，并非声称同一次完整运行零失败。
• 工具清单：70 个页面操作、18 个模块与实际适配器一致；另外核查全局工具参数。
• Android 隔离应用：56 项写入/检索 + 11 项进程重启后读取，共 67 项通过；完整流程重复后仍通过。测试应用已卸载。
• 后台：36 项通过，覆盖账号与邮箱校验、鉴权、二手信息、图片限制、通知/雷达解析及测试隔离。邮件使用内存模拟，未向用户发信。
• Release 构建和 vital lint 通过。安装包签名与 0.61.0 相同，未包含 debug 审计入口。

重点修复
1. 口语纠正：避免“不是收入，是午饭花了十八块”被拆为删除旧账再记新账；修改旧账保持 ID 与日期。账单金额和昨天/前天等日期不再从无关记录补齐。
2. 执行与反馈：只读权限、跨页面显式目标、未指定时间、数量与时长、遗漏操作分别校验；修复“新建并开始录音”只建空记录的问题。新录音的标题不再误用当前选中的旧记录。
3. 错误恢复：格式错误、缺参、错误对象 ID 可在写入前有限修复；查询失败不能伪装成功。部分附件保存成功按“部分完成”显示，并保留真实保存结果供后续追问。
4. 资料库：已保存文件的真实 ID 和来源证据随对话保留；命名规则等跨段内容保留相邻原文。文件问题先查本地资料，避免要求用户重新发送已经保存的资料。附件重复保存和并发保存增加幂等保护。
5. 录音检索：课程名、录音名和关键词可以分开匹配，输出录音次序/名称、时间和原文。重复查询不能无休止循环。
6. 通知与弹幕：来源折叠 expanded 与摘要显示 summary 明确分开；不再用隐藏摘要代替折叠来源。已有弹幕内容先读取，真正为空时再询问。
   晨签单独修改统计时间时只传 time，保留原统计范围，不再追问无需修改的起止日期。
7. 工具参数：拒绝未知字段、错误类型、无效目标和被忽略的组合要求；删除已无效的参数声明。读操作不再被当作待批准的写操作。
8. 后台测试：修复导入应用时可能初始化默认数据目录的问题；所有测试提前切换到独立临时目录并阻断外网与真实 SMTP。
