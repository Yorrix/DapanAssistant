原则
- AI 栏在常规功能页面保持可用，页面只提供指代语境，绝不限定可调用工具。
- 统一能力清单来自真实处理函数：58 个页面操作 + 10 个全局操作；另外保留核心数据动作。
- 已有记录先读取真实 ID/内容；含糊对象和必要信息缺失须澄清。执行结果由应用返回。
- 一般控制展示中文操作清单，完全控制直接执行，只读禁止写入、录音、计时、发布。运行前重新检查权限；所选对象改变会使旧确认失效。

逐项覆盖（代码路径核查；不等于真实模型/手机端全场景已验证）
今天 / 工具：提供今日事项、收藏、工具筛选语境；可调用全部工具；收藏/取消收藏。
日历 / DDL / TDL / 全天：新增、编辑、删除、完成；日周/日期/列表切换；分类增删；原有 1～64 项核心数据原子批量。
账单：新增/改动/删除/查询真实记录；月份切换。首页说午饭18.50元 → 吃饭类别支出；缺金额询问。
抽签：轮盘新建、编辑、选择、删除、配置、实际加权随机转动；支持保存后立即转动。三人1:1:2对应25%/25%/50%，缺姓名先问。
晨签：历史日期标记、读取、统计起止与通知时间配置、月历切换；未来手工标记不提前计入统计。
取件码：复用原有记事记录增加/更改/删除/查询，当前输入可供理解指代。
信息查询：个人/老师/校园服务键值资料增改删查，分组和搜索切换。
官网通知：读取真实缓存及来源、筛选、查看、同步、打开原文。缓存日期明确；不编造最新消息。
二手信息：查询/详情、编辑入口、任意页面新建草稿或明确授权发布、填当前草稿、选图上传、发布、完成/下架/删除。联系方式只用用户提供值；登录及验证码由用户手动填写。
天气：读缓存并标明时间，刷新、晨间通知开关/时间；无数据时不凭空预测。
地图 / 热力图：实际点位查询、起终点/朝向/缩放/焦点、导航与热力模式/统计日期、开始/停止记录和清空；系统定位授权仍手动。
专注：设置时间和通知/来电、开始/停止；专注计时内保留AI栏，可跨工具调用。
手持弹幕：文字、字号、速度、颜色、方向、滚动、闪烁、粗体、抖动及全屏展示。
会议摘要：会议/课程创建，查询会议和匹配的转写时间点，定位回听、暂停、新录音/停止、摘要/取消、重命名、重排、重转写、修正/恢复文字、导出及删除单段或整组。
实时翻译：语言/术语/偏好/显示配置、文字翻译、开始/停止实时收听、历史查询和清空。启动与完成分开回执，不声称后台工作已完成。
资料库：任意文件导入、保存AI附件、改名/备注、打开、导出、删除副本、重新索引、跨页面查找和读取可提取正文。
扫描文件：AI可打开现有离线扫描器；最终文件进入资料库。只读模式不允许AI开启可能自动保存的扫描器。
设置：AI只可切换主题；权限、密钥、账号凭证由用户直接设置。

必要交互与剩余边界
- 系统权限、文件选择/导出位置、账号登录/验证码仍需要用户完成。
- 独立全屏相机、全屏弹幕和系统/外部查看器没有嵌入AI栏；返回常规页面后继续使用。模态编辑弹窗先关闭再使用AI栏。
- 核心数据批量支持原子保存；异步工具不支持任意跨工具事务批量，也不会虚称整个流程完成。已补常见组合：新轮盘+立即抽签，新会议+录音，二手草稿+填写/发布。
- 多轮查找有上限，匹配及正文有截断标记；本轮未加入向量检索或OCR。图片、图片型PDF、旧版Android上的PDF可搜名称和备注。Office和大文本只索引限定篇幅。
- 资料库单文件256MB；AI临时附件单文件16MB、一次4个；不支持格式可以保存，不能声称读懂其正文。图片/PDF在本次AI附件消息内可按既有图片通道分析，和资料库正文索引是两回事。
- 通用JSON备份不含资料库、录音和工具全部设置；界面已明确说明。
- 网络写入后遇到刷新失败会保留已提交回执；取消已提交请求不能撤销远端操作，请先查看记录再重试。
- 仍需用户实机体验自然语言理解、跨页面连续交互、权限弹窗、语音、视觉手感。不能保证任何表达都百分之百理解正确。
