# 1.0.0 发布说明

版本号 1.0.0，内部版本号 100；由完成口语问题修复的 0.64.2 升级版本标识，应用功能保持一致。

保留自然语言工具调用、日程与课表导入、校园服务、资料库、录音工具、可编辑首页及悬浮小助手。包含使用与数据声明、按需权限引导、快速入门，以及应用内检查、下载和确认安装更新。

相较上次 0.64.0 提交包，修复重复确认语未识别、已确认提醒时间被课程时间覆盖、改口后仍套用旧时间关联等问题；检索适应简短口语关键词，校园热词包含 assignment。含混的删除或完成要求只追问真正缺失的信息，不擅自删除。

原始 0.64.2 口语回放共 28 个虚构场景通过，包含停顿、重复、否定及改口，实际为 31 次模型请求。它们是转写后的理解和执行验证，不是音频识别准确率测试。原始失败统计与修复后结果保留在历史记录中。

1.0.0 的当前构建、单元测试、后端测试、签名及打包检查以“源码/校验/1.0.0”记录为准，不将历史结果冒充本次新测试。仍需用户真实使用反馈；不宣称所有表述、所有机型和后台提醒均已穷尽验证。

本次结果：1245 项应用测试通过、1 项需手动启用的在线测试跳过；82 项后端测试通过。发布静态检查无错误，保留 340 条已有警告。交付 ARM64 APK 在兼容模拟器从 0.64.1 覆盖安装至 1.0.0，冷启动及今天、日历、工具页面检查通过。
