# 1.0.3 · 连续日历与紧凑日期

发布日期：2026-10-31；版本码：103。

- 日期横向连续滚动，不再限制周一至周日；跨周、跨月自动加载相邻日期。
- 点击“今天”或左上角日期选择器，将目标日期放到屏幕中间。日期范围随视图更新。
- 左右箭头仍移动七天，保留缩放和时间轴位置；切页返回也保留当前视图。
- 日期标题使用 `MM.dd~MM.dd`，跨年也不显示年份；字号根据可用宽度调整。
- 按可见日期缓存日程布局，日期、全天事项和时间轴使用相同的横向位置。

此次源码同步同时补齐已上线的 1.0.1 对话反馈功能：用户确认后才上传当前对话；反馈和额度后台使用唯一管理员登录。更新不修改既有账号和数据。

验证范围见仓库 README 和 `校验/1.0.3/发布检查.json`。未重复宣称已通过历史全量测试，也未重新测试所有手机机型。
