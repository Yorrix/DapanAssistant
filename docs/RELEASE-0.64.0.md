# 0.64.0（97）更新

- 首次使用展示使用与数据声明；同意后进入权限引导，逐项申请通知、麦克风、定位、相机权限。可跳过，后续在设置中管理。拒绝、近似定位、返回设置等状态分别处理。
- 自动检查新版，用户选择下载后在应用内显示进度，可取消和重试。安装前核对大小、SHA-256、包名、版本和签名，再打开 Android 系统安装确认。缓存失效时允许重新下载。设置中可关闭自动检查。
- 修复“在明天某课下课时”“上完某课后”等日程时间关联，使用真实课程时间，保留用户指定时长；找不到或存在多条候选时不会猜测。
- AI 内部检索、参数修正不再逐次展示临时回答，一轮请求只呈现最终结果或一条失败说明。相同失败操作提前结束重试，兼容模型多包一层格式元数据的完整回复。
- 作品说明增加自动更新介绍，保留直接打开 App、跟随快速入门，无需先看视频的建议。
