# 大盘助手

面向大连理工大学盘锦校区的 Android 校园生活助手。把课程、日程和生活工具集中在一起，也可以直接用自然语言让 AI 调用它们。

**版本：0.61.4（89）｜Android 8.0 及以上｜提供 arm64-v8a 安装包**

## 源码入口

**源码仓库：[Yorrix/DapanAssistant](https://github.com/Yorrix/DapanAssistant)**。当前目录是正式提交包对应的源码快照。

作品说明、演示视频和安装包统一放在完整参赛包顶层，源码内不再重复保存。项目构建见 [BUILD.md](docs/BUILD.md)，现存修改记录见 [历史索引](docs/history/README.md)。

## 主要功能

- **AI 与日程**：自然语言操作、课表导入、周历、DDL、TDL、出发提醒；需要批准、完全控制和只读三种权限，支持的操作可撤销。
- **校园服务**：晨签、官网通知摘要与关注、二手信息、校园导航与热力图、个人信息与校园服务查询。
- **资料与录音**：资料库检索、图片文字识别、扫描文件、录音摘要、实时翻译、课堂生词。
- **日常工具**：天气、记账、取件码、专注、抽签、手持弹幕；可自定义首页组件、形状与配色，也可开启悬浮小助手。

## 体验方式

参赛完整包顶层的 `大盘助手-0.61.4.apk` 可直接安装；源码内不重复保存 APK。

首次启动可选择公用 AI 或自备 API：公用服务需要大工邮箱账号，定位为基础试用，延迟可能较高；自备模式分别配置 DeepSeek（对话）与阿里云百炼（语音）。公用额度为每人每天 1 元、每周 3 元，全站每月 30 元，额度和服务可用性受实际运营状态影响。

对话、短语音及任务所需资料使用公用 AI 时经过开发者部署的服务器。长时转写、持续翻译、课堂生词等不计入公用试用；相应在线能力需要个人配置。扫描模型和离线词典在 App 内按需下载，不需要另装组件 APK。

## 构建与验证

用 Android Studio 打开本目录并安装 Android SDK 37。使用 Android Studio 自带 JDK，准备 Python 环境。详见 [构建说明](docs/BUILD.md)。

```powershell
# JAVA_HOME 和 ANDROID_HOME 指向你自己的 JDK、SDK。
./build-local.ps1 -Python python -RunTests
```

构建脚本不连接部署服务器，不自动安装手机，也不调用付费模型。在线 AI 评估需明确执行独立脚本并提供自己的密钥及预算。
