# 大盘助手

面向大连理工大学盘锦校区的 Android 校园生活助手。用日常语言管理课程、日程和待办，也能查资料、记账、抽签、查通知和校园路线。

**正式版 1.0.0（100） · Android 8.0 及以上 · arm64-v8a**

## 安装体验

[下载 1.0.0 安装包](https://39.105.161.86/updates/dapan-100.apk)

建议直接打开 App，跟随快速入门配置并导入课表。已有带更新功能的版本可在“设置 → 应用更新”检查并升级，覆盖安装保留数据。

公用 AI 需大工邮箱登录，受账号与全站额度限制；也可填写自己的 DeepSeek 与阿里云百炼 API。使用公用 AI 时，任务数据经过开发者部署的服务器，图片公用识别由用户主动确认。系统权限按需申请。

## 主要功能

- **AI 与日程**：自然语言创建、查询和批量修改课程、日程、DDL、TDL，支持课表导入、出发提醒和晨签。助手权限可选只读、需要批准、完全控制，支持的修改可撤销。
- **校园生活**：官网通知与关注提醒、二手信息、参考导航、热力图、天气及生活工具。
- **资料与录音**：资料库收纳与检索文件、扫描、录音摘要、实时翻译、课堂助手与课堂生词。
- **个性化**：可编辑的今天页、独立形状与配色、悬浮小助手。
